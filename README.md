# Budget Buddy

A local-first, privacy-focused expense and budget tracker for Android. Track income and expenses, set and monitor a monthly budget, keep payment reminders, and manage everything through a built-in assistant that understands plain-English commands.

All your data stays on your device, there's no account, no cloud sync, no server, and no ads.

## Download

Grab the latest APK from the **[Releases](../../releases)** page and install it directly on your Android device.

> This repository is a source-available/closed-source distribution point — it hosts release builds only. The source code is maintained privately.

### Installing
1. Download the `.apk` file from the latest release
2. On your Android device, you may need to allow installs from your browser/file manager the first time (Settings → Apps → Special access → Install unknown apps)
3. Open the downloaded file and tap Install

Minimum Android version: **Android 8.0 (API 26)** and up.

## Features

- **Home** - balance overview, income/expense summary, monthly budget progress bar (green when on track, red when over), payment reminders, and recent transactions
- **Budget** - set a monthly budget, track it against the calendar month or your own custom reset day (e.g. payday), and save/load full budget setups
- **Balance Sheet** - a complete transaction ledger with an income-vs-expense breakdown chart and running balance total
- **Profile** - local profile, a currency picker covering virtually every country, light/dark/system theme, and a one-tap privacy mode that hides all amounts on screen
- **Moe Assist** - a built-in assistant for adding, editing, and querying your finances using plain-English commands like *"spent 250 on groceries"*, *"what's my balance"*, or *"remind me to pay rent 3000 on day 1"*, entirely on-device, no internet connection required

## Privacy

Budget Buddy stores everything locally on your device using SQLite and Android's SharedPreferences. Nothing is transmitted anywhere. There is no analytics, no tracking, and no third-party data sharing of any kind.
